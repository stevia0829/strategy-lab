# 功能验收记录

日期：2026-09-16。软件功能验收不等于策略收益验证；合成行情不得用于投资结论。

## 自动检查

- `make test`：Go 全部测试通过；Python 35 个测试方法中 34 个通过，1 个需要单独指定 PostgreSQL 测试库的集成用例在常规运行中跳过。
- `make parity`：4 个内置策略模板的独立 Go／Python 计算结果在既定浮点容差内一致。
- 自写策略测试覆盖信号只读取截至当日的行情、下一交易日开盘成交、非法目标拒绝；模型接口测试使用替身请求，不调用付费模型。
- `strategy-lab-script` Skill 通过格式校验，容器镜像可以读取；替身模型请求验证资产池与持仓上限进入系统提示、密钥不进入提示或返回结果、无效草稿被拒绝。
- JavaScript 语法、Python 编译检查、Docker Compose 配置检查通过。

## 浏览器与完整部署

- 三容器部署（应用、PostgreSQL、无网络 worker）均通过健康检查；未授权的历史接口返回 401。
- Python 和 Go 自写代码均在 worker 中完成合成行情回测，返回实际成交与历史记录编号。
- 浏览器依次验证策略输入、简单策略、运行回测和历史回测记录；确认收益图、成交明细、报告下载及历史记录重新打开。模型供应商切换会更新建议模型 ID。
- 在无 PostgreSQL 驱动的本机轻量模式中，浏览器仍能得到合成数据回测报告，并提示历史记录未保存。
- 真实行情使用 510300 ETF 与沪深300指数 000300：首次从公开接口取数，重复请求命中 PostgreSQL；指数使用原始日线，ETF 使用前复权日线，并生成基准曲线。
